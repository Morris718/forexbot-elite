# ForexBot Elite Pro

AI-powered forex trading platform with real-time WebSocket price feeds, 
live charts, position management, and AI signals.

## Features
- Real-time tick engine (16 pairs: FX, Gold, Crypto, Indices)
- Live moving charts with bid/ask spread
- Position management with live P&L
- AI signals (Technical + Sentiment + ML + Fundamental)
- Demo trading with $100K virtual balance
- Live support chat with auto-reply agents
- Deposit/Withdrawal system
- Multi-session tracking (Sydney/Tokyo/London/NY)

## Tech Stack
- Flask + Flask-SocketIO + Eventlet
- SQLAlchemy + SQLite
- Vanilla JS Canvas charts
- WebSocket real-time updates
